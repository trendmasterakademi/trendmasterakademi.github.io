The developer says 'it works on my machine' and they are correct. In production, identical code behaves differently. This is environment drift, not a developer competency flaw.

Urgency: High · release blocker · Category: Handover & Continuity

Field Observations

Developers provide screen recordings demonstrating flawless functionality on local and staging servers. Yet the moment code hits production, blank screens, 500 errors, or missing data appear, triggering finger-pointing between teams.

Observed System Error Signatures

  • Undefined env variable / configuration missing → A · Configuration drift
  • Fails with 500 only on production, passes 200 on staging
  • Dependency versions: lockfile present and synchronized?
  • Permission denied - file permissions or path mismatch → C · Permissions / path discrepancy

Environment drift always lives in one of three places: configuration, dependency versions, or file permissions. Searching elsewhere wastes critical incident time.

Three Potential Root Causes & Differential Tests

A · Configuration drift

Production environment variable missing or set to invalid endpoint. Same code, differing inputs.

Differential test: Is an environment variable missing in production?

Evidence: Missing .env in production → A

Resolution: Sync .env schema + track .env.example in git

Common anti-pattern fix: Manually copying script files to staging overlooks discrepancies in PHP extensions or MySQL strict mode flags between the two server runtimes.

B · Dependency / runtime mismatch

Language or package minor versions differ between environments. Unlocked package versions drifted.

Differential test: Are lockfile package versions identical across tiers?

Evidence: Version mismatch in lockfile → B

Resolution: Commit strict package-lock / composer.lock

Common anti-pattern fix: Hardcoding missing environment variables directly into application logic fails when credentials rotate or repositories are deployed to new infrastructure.

C · Permissions / path discrepancy

Target directory lacks write permissions on production web server, or hardcoded absolute path fails.

Differential test: Does log show EACCES / permission denied errors?

Evidence: Permission denied in production log → C

Resolution: Fix chmod permissions + load dynamic paths

Common anti-pattern fix: Validating queries on ten mock records fails to reveal that production tables with hundreds of thousands of rows exhaust PHP memory.

Resolution Path & Time to Fix

Backend / DevOps. Permanent stability comes from Infrastructure as Code and immutable container recipes; patching discrepancies ad-hoc leaves every future release vulnerable.

Impact If Left Unresolved

Every deployment becomes a high-stakes gamble. Teams dread pushing to prod, backlogs swell, and large batch deploys magnify catastrophic blast radiuses.
