Desteklenen Teknolojiler & Cerrahi Müdahale Derinliği

Node.js (Nest / Express / Fastify)

SEV-0 / SEV-1

Hazırbulunuşluk: Anında SWAT Triyajı — İlk yanıt SEV-0 ≤ 15 dk · SEV-1 ≤ 30 dk

Kritik Arıza Noktaları:

  • Event Loop blokajı & senkron CPU döngüleri
  • Unhandled Promise Rejection kaynaklı sessiz çöküşler

TMA SWAT: V8 Heap snapshot analizi, Chrome DevTools CPU profiler, Clinic.js alev grafikleri (flamegraphs), libuv thread pool optimizasyonu ve kümeleme (clustering) cerrahisi.

Python (Django / FastAPI / Flask)

Kritik Arıza Noktaları:

  • Django ORM n+1 sorgu felaketleri ve bellek şişmesi

TMA SWAT: Py-Spy / cProfile ile canlı süreç profillemesi, async/await darboğaz eliminasyonu, Celery prefetch ve concurrency tuning, ORM sorgu optimizasyonu.

Go (Golang)

SEV-0 / SEV-1

Hazırbulunuşluk: Anında SWAT Triyajı — İlk yanıt SEV-0 ≤ 15 dk · SEV-1 ≤ 30 dk

Kritik Arıza Noktaları:

  • Goroutine sızıntısı (Goroutine Leaks) ve bellek tükenmesi
  • Race Condition (Eşzamanlı bellek erişim çatışmaları)

TMA SWAT: pprof heap/goroutine/mutex dump analizi, Go race detector ile yarış koşulu tespiti, kanal mimarisi refactor'ı ve sync.Pool ile sıfır-tahsis bellek optimizasyonu.

PHP (Laravel / Symfony)

TMA SWAT: PHP-FPM pm.max_children ve request_slowlog incelemesi, Laravel Octane (Swoole/RoadRunner) migrasyonu, query indexing ve cache katmanlaması.

Java / Spring Boot

TMA SWAT: JProfiler / VisualVM heap dump & thread dump analizi, G1GC / ZGC tuning, HikariCP havuz optimizasyonu ve native sorgu izolasyonu.

PostgreSQL

SEV-0 / SEV-1

Redis (Cache & Message Broker)

SEV-0 / SEV-1
