Technical Glossary — 12 Terms

  • → Deadlock Critical (P0)

    A situation where two database transactions mutually block each other by holding locks that the other requires, freezing queries.

  • → N+1 Query Problem Medium / High

    An ORM efficiency bottleneck where the application executes 1 initial query plus N additional queries for child records instead of a single batch query.

  • → Race Condition Critical (P0)

    A concurrency flaw where multiple threads or requests execute operations out of anticipated order, causing data corruption.

  • → Idempotency High

    A mathematical and API principle ensuring identical requests executed multiple times yield the exact same result without duplicate side-effects.

  • → Webhook Critical (P0)

    An automated user-defined HTTP POST callback triggered by external service events like completed transactions or SMS deliveries.

  • → Technical Debt Medium / Strategic

    The implied long-term cost of additional rework caused by choosing an easy, fast software shortcut over a sustainable architectural design.

  • → Refactoring Medium

    The process of restructuring existing computer code without changing its external behavior to improve non-functional attributes.

  • → CI/CD Pipelines High

    A combined automation pipeline (Continuous Integration / Continuous Deployment) that builds, tests, and deploys code changes seamlessly.

  • → Staging Environment Medium

    An isolated pre-production environment that mirrors the exact production infrastructure, databases, and dependencies for QA.

  • → Database Migration High

    Programmatic, version-controlled scripts that modify database schemas safely across different developer and production environments.

  • → Rate Limiting High

    A defensive network strategy limiting the frequency of requests a client or bot can send to an API endpoint within a given time window.

  • → Memory Leak Critical (P0)

    A programming defect where dynamically allocated memory is never released by the application, steadily degrading RAM until crash.
